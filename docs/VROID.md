# VRoid 캐릭터 제작 가이드

플레이어 캐릭터 2종을 VRoid Studio로 만들어 `.vrm`으로 내보내는 절차.

게임 코드는 `public/models/`에서 파일을 찾는다. **파일이 없으면 기존 코드 생성
모델로 자동 폴백**하므로, 아직 안 만들었어도 게임은 정상 동작한다.

| 클래스 | 파일명 (정확히 이대로) | 컨셉 |
|---|---|---|
| 일현(日弦) · 원거리 | `public/models/ilhyeon.vrm` | 백은발 마법사. 흰·하늘색 로브, 시안 포인트 |
| 월아(月牙) · 근접 | `public/models/wola.vrm` | 흑발 여자 사무라이. 감청 하카마, 진홍 포인트 |

---

## 1. 설치

<https://vroid.com/en/studio> 에서 **VRoid Studio (Stable)** 를 받는다. 무료.
Steam판도 같다.

> Stable 버전으로 만든 모델은 **상업적 이용이 명시적으로 허용**된다.
> (금지 조항은 "VRoid 메시·텍스처를 조합해 모델을 뽑아내는 앱을 만드는 것"이라
> 우리와 무관하다.) 근거 링크는 `ASSETS.md`에 기록해 둘 것.

---

## 2. 만들기

새 모델 → **여성** 프리셋으로 시작. 프리셋을 고르면 이미 완성된 캐릭터라
아래 항목만 손봐도 충분하다. 얼굴을 처음부터 조각할 필요 없다.

**꼭 건드릴 것 (실루엣에 영향이 큰 순서)**

1. **헤어** — 프리셋 헤어 중 하나 고르고 색만 바꾼다.
   - 일현: 밝은 은발/백금발 (`#DCEBFA` 근처)
   - 월아: 흑발 (`#1B1F28` 근처), 포니테일 계열이면 스프링본이 잘 흔들려 좋다
2. **의상** — 프리셋 의상 + 색 변경.
   - 일현: 흰 바탕 + 하늘색 트림. 롱스커트/로브 계열
   - 월아: 어두운 감청/남색. 하카마나 기모노 계열, 없으면 어두운 상하의
3. **눈동자 색** — 이게 클래스 식별 신호다. 반드시 바꿀 것.
   - 일현: 시안 `#4DD0FF`
   - 월아: 진홍 `#FF5A6E`
4. **체형** — 신장은 기본값 그대로 둔다(코드가 알아서 스케일 맞춘다).
   머리 크기를 조금 키우면 애니메 비율이 강해진다.

**시간 배분**: 캐릭터당 20~30분. 완벽하게 다듬지 말 것 — 게임에서는
쿼터뷰로 멀리서 보이므로 헤어 실루엣·의상 색·눈 색만 맞으면 충분하다.

---

## 3. 내보내기 (설정이 중요하다)

`파일 → VRM으로 내보내기`

| 항목 | 값 | 이유 |
|---|---|---|
| **VRM 버전** | **VRM 1.0** | 현재 규격. 로더가 0.x도 받지만 1.0이 변환 단계가 없다 |
| **폴리곤 삭감** | 기본값 유지 | 안 보이는 메시 제거 정도면 충분 |
| **머티리얼 삭감 (머티리얼 수)** | **4** 정도 | 드로우콜이 줄고 텍스처가 아틀라스로 합쳐진다 |
| **텍스처 해상도** | **1024** | 쿼터뷰에서 2048은 낭비다. 파일 크기가 1/4로 준다 |
| **블렌드셰이프 삭감** | 켬 | 표정 모프를 안 쓴다 |

메타데이터(제작자·이용조건)는 본인 것이므로 아무렇게나 채워도 된다.
`허가 없이 사용 가능`으로 두면 편하다.

**목표 파일 크기: 하나당 5~15MB.** 30MB를 넘으면 텍스처 해상도나
머티리얼 수를 더 낮춘다.

---

## 4. 넣기

내보낸 파일을 아래 경로에 **정확한 이름으로** 둔다.

```
E:\NAN 2026\public\models\ilhyeon.vrm
E:\NAN 2026\public\models\wola.vrm
```

그리고 알려주면 된다. 나머지(로드·셰이딩·스케일·회전·QWER 모션 재매핑)는
코드가 처리한다.

---

## 5. 코드 쪽에서 자동으로 되는 것

직접 안 해도 되는 것들:

- **툰 셰이딩** — VRM 규격의 MToon 머티리얼이 그대로 살아난다.
  지금 프로시저럴 모델의 PBR 음영(플라스틱 느낌)이 사라지고 셀셰이딩이 된다.
- **머리카락·치마 물리** — VRM 스프링본을 매 프레임 돌린다.
  걷고 대시할 때 알아서 흔들린다. 손으로 짠 hairChain 코드가 필요 없어진다.
- **신장 정규화** — VRoid 기본 신장이 얼마든 게임 스케일(1.75)에 맞춘다.
- **정면 정렬** — VRM은 +Z를 보고 우리 sim은 +X 규약이라 90도 돌려 붙인다.
- **QWER 시전 포즈** — VRM 휴머노이드 본에 절차적 포즈를 얹는다.
