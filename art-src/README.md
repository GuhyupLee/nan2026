# art-src — 생성 원본

Codex CLI(`image_generation`)로 생성한 원본 이미지. 손으로 수정하지 않는다.

`npm run art` 가 이 디렉터리를 읽어 `public/art/` 에 WebP를 굽는다.

원본을 리포에 함께 두는 이유는 AI 활용 문서의 증거 사슬을 리포 안에서
끊기지 않게 하기 위해서다 — 생성 프롬프트, 생성 원본, 최적화 스크립트,
최종 산출물이 모두 같은 저장소에 있고 커밋 기록으로 순서가 남는다.

## 생성 이력

| 파일 | 도구 | 용도 |
|---|---|---|
| `portraits/magic-girl.png` | Codex CLI 0.145.0 · image_generation | 원딜(빛 마법사) 캐릭터 선택·레벨업 초상 |
| `portraits/samurai-girl.png` | Codex CLI 0.145.0 · image_generation | 근딜(여자 사무라이) 캐릭터 선택·레벨업 초상 |

두 장은 같은 프롬프트 세션에서 생성해 화풍·선 두께·채색·조명을 일치시켰다.
프롬프트에 기존 게임 캐릭터를 연상시키지 말 것을 명시했다.

## 클래스 컬러 언어

두 초상의 색 대비가 그대로 클래스 정체성이 된다. 인게임 저폴리 모델과
스킬 이펙트가 이 팔레트를 따라야 2D와 3D의 정밀도가 달라도 같은 캐릭터로 읽힌다.

| 클래스 | 팔레트 | 인상 |
|---|---|---|
| 원딜 (마법사) | 시안 · 화이트 · 골드 | 차가운 빛, 정적, 거리 유지 |
| 근딜 (사무라이) | 크림슨 · 블랙 · 실버 | 뜨거운 칼날, 역동, 파고들기 |
